# ENG-008 — CI for unit tests and svelte-check

- **Priority:** P1
- **Type:** Infrastructure
- **Status:** BACKLOG
- **Dependencies:** ENG-007

## Description

GitHub Actions installs both packages, runs backend unit tests, and runs the frontend check. Oracle is not required.

## Problem Statement

Nothing fails a bad commit today.

## Implementation Scope

In: `.github/workflows/ci.yml`. `npm audit` is recorded and does not fail the job on pre-existing advisories.

Out: an Oracle service container and deployment.

## Acceptance Criteria

- The workflow runs `node --test` in `backend/` and `npm run check` in `frontend/`.
- The default job does not require `ORACLE_CONNECT_STRING`.

## Testing Requirements

The workflow file is valid YAML and names those commands. A local `node --test` run is the stand-in when Actions cannot be executed here.

## Definition of Done

Workflow committed. Local unit tests pass. Commit contains only this ticket's files.
