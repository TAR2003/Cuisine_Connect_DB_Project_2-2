# ENG-004 — bcrypt password storage

- **Priority:** P0
- **Type:** Security
- **Status:** DONE
- **Dependencies:** ENG-003

## Description

Hash and verify passwords with bcryptjs in Node. Remove `CHECK_PASS` from the request path.

## Problem Statement

`ORA_HASH` is a fast 32-bit bucket, not a password hash.

## Implementation Scope

In: `bcryptjs` on register, login, and password change. `USERS.PASSWORD` widened to `VARCHAR2(255)` in the rebuild script. Seed password read from `SEED_PASSWORD`.

Out: rewriting unrelated SQL.

## Acceptance Criteria

- A wrong password fails verification.
- A correct bcrypt hash verifies.
- The server does not call `CHECK_PASS`.

## Testing Requirements

Unit tests for verify failure and success.

## Definition of Done

Tests pass. No `ORA_HASH` remains on the login or password-update path. Commit contains only this ticket's files.
