# ENG-001 — Secrets, pool, and a single entry point

- **Priority:** P0
- **Type:** Security
- **Status:** DONE
- **Dependencies:** none

## Description

Remove committed database credentials, start from the environment, use one Oracle pool, and leave a single server entry point.

## Problem Statement

The database password is in source and the README. Every query opens its own connection. A stale root server can be started by mistake.

## Implementation Scope

In: `.gitignore`, `backend/.env.example`, `backend/src/config.js`, `backend/src/db.js`, pool usage in `backend/server.js`, README credential removal, password log removal, deletion of root `server.js` and `index.html`, move of scratch SQL to `database/scratch/`, drop of the `fs`, `path`, and `image-type` npm dependencies.

Out: sessions, authorization, bcrypt, schema redesign.

## Acceptance Criteria

- The process exits before listen when `ORACLE_USER`, `ORACLE_PASSWORD`, or `ORACLE_CONNECT_STRING` is missing.
- Source and README contain no database password.
- A unit test covers the missing-environment failure.
- `app.listen` runs after routes are registered and the pool is created.

## Testing Requirements

`node --test` on the config test.

## Definition of Done

Acceptance criteria met, test run, commit contains only this ticket and the tracking docs if they are not already committed.
