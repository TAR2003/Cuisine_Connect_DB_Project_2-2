# ENG-005 — Ordered schema rebuild

- **Priority:** P0
- **Type:** Infrastructure
- **Status:** READY
- **Dependencies:** ENG-004

## Description

One ordered, destructive rebuild for an empty Oracle user: tables, constraints, indexes, sequences, functions, triggers, and a development seed.

## Problem Statement

Sequences live in a scratch file. The README install order fails on the first `NEXTVAL`. Several keys do not match how the API uses the tables.

## Implementation Scope

In: `database/rebuild/` ported from the current SQL, plus the approved key, uniqueness, status, session, and admin-log corrections.

Out: applying the script when no local Oracle user is reachable. Do not claim the schema was created in that case.

## Acceptance Criteria

- The script is ordered and contains every sequence the server uses.
- Seed creates one admin, one customer, one restaurant, and one menu, with bcrypt hashes produced outside SQL text.
- Scratch SQL is not the installer.

## Testing Requirements

Static check that required sequences and tables are present. Apply on Oracle only if a connection succeeds.

## Definition of Done

The script is in the repo. Oracle application result is recorded honestly. Commit contains only this ticket's files.
